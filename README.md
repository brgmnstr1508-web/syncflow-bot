# 🤖 SyncFlow Bot

Современный Telegram-бот с интеграцией нейросети GigaChat и системой управления платными подписками.

## ✨ Основные возможности

- 🧠 **Интеграция с GigaChat**: Использование мощной языковой модели для генерации ответов.
- 💳 **Система подписок**: Встроенный механизм управления платным доступом для пользователей.
- 🗄️ **Надежное хранение данных**: Работа с базой данных для сохранения пользовательских настроек и истории.
- ⚡ **Асинхронная работа**: Быстрый и отзывчивый интерфейс благодаря современному стеку Python.
